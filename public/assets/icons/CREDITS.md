# Icônes

Les icônes utilisées dans `public/assets/icons/` proviennent du pack **Crystal Clear**
par Everaldo Coelho, publié sous licence LGPL (libre réutilisation, y compris modification).

- folder-128.png / folder-64.png → folder_blue
- photos-128.png → lphoto
- notes-128.png → kwrite
- file-64.png → empty (icône fichier générique)

Si tu changes de pack d'icônes plus tard, remplace simplement ces fichiers en gardant
les mêmes noms (référencés dans `index.html` et `app.js`).
